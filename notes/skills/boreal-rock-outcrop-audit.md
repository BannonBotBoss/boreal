# Skill: Boreal Rock, Outcrop & Forest-Floor Prop Audit (`boreal-rock-outcrop-audit`)

Use when inspecting, implementing, or verifying geological features (rocks, glacial erratic boulders, Canadian Shield whaleback bedrock outcrops, shoreline cobbles, slope seating, crustose lichen/moss shading) and forest-floor prop scale (`forage`, `plant`, `log`) against ecological and geological sources. Created and refined by `agy` for `T-0026` (`refs/rocks/shield-audit/`).

## Steps
1. **Probe the generator across chunks with `STAGES.on = true` (`refs/rocks/shield-audit/probe.ts`):**
   - Always set `STAGES.on = true` (matching `world.stagedTerrain` default in `renderSettings.ts`) and center the sample grid on `dryStart(0, 0)` from `src/core/stages/surfaceAt.ts`.
   - Measure rock counts per dry-land hectare, Wentworth size-class histogram (`pebble < 0.064 m`, `cobble 0.064–0.256 m`, `boulder 0.256–2.0 m`, `whaleback-outcrop > 2.0 m`, Wentworth 1922; Dredge & Cowan 1989), Clark-Evans nearest-neighbour index $R$, fraction of stones on bedrock uplands (`siteAt(x, z).rock > 0.3`), and fraction of stones whose height (`rockDiameter(e) * ROCK_SHAPES[shape][1]`) is less than or equal to the local organic forest floor thickness (`column(x, z)` in `src/core/ground.ts`: `moss + freshLitter + fragmented + duff + humus + peat`).
2. **Causal rock placement without `heightAt`/`riverAt` stalls (`src/core/rocks.ts`, `src/core/world.ts`):**
   - Never call `siteAt(x, z)` or `column(x, z)` inside the 120-stone loop of `generateChunk(cx, cz)`: `column` calls `generateChunk` (infinite recursion), and `siteAt` calls `heightAt` 5 times (`600` `riverAt` calls per chunk, stalling the 4 ms frame budget).
   - Instead, use `fastRockSite(x, z)` in `src/core/rocks.ts`, which performs 4 O(1) array reads on `soilGrid(STAGES.seed).kind` (`0 = bedrock`, `4 = peat`, `5 = water`), and pass the already-evaluated `h = heightAt(x, z)` into `placeRockSeed(x, z, h, baseSeed, isCandidate)`.
   - Encode boulder and whaleback outcrop size tiers (`tier = 1..3` -> `size = 9..11` = `0.95 m`, `1.65 m`, `3.60 m`) in the upper integer bits above `0xffffffff` via `withRockTier(seed, tier)` (`(seed >>> 0) + tier * 0x100000000`). Because `random(seed)` uses `seed | 0`, the 32-bit RNG stream is unchanged while `rockRecipe(e.seed)` and `rockDiameter(e)` deterministically decode the boulder/outcrop size without depending on `e.scale`.
   - When `generateChunk` rock placement changes intentionally, re-pin the world-chunk baseline digest in `tests/proc.test.ts` in the same commit (leaving the fur digests untouched) and run the full `npm test` suite.
3. **Slope-conformed whaleback & boulder geometry, linear reflectance, and smooth dome shading (`src/render/rocks.ts`, `src/render/batch.ts`):**
   - **Linear vs sRGB albedo:** Three.js `r180` vertex `color` attributes and shader `diffuseColor.rgb` are in **linear** working colour space. Passing `0.45–0.60` into `THREE.Color.setRGB()` sets a `50%` snow/limestone reflectance that blows out to a flat cool white slab under ACES Filmic tone mapping and blue-sky IBL. Always use physical linear reflectance: for Canadian Shield pink-grey orthoclase granite / quartz monzonite (USGS Spectral Library *Granite HS19.3B*; Sentinel-2 Kenora bare outcrop `~0.14–0.22`), use linear RGB `(0.24..0.32, 0.175..0.235, 0.13..0.175)` with per-vertex basal contact darkening (`0.44..1.0` near the emerging ground perimeter).
   - **Smooth dome normals + derivative bump:** Set `ROCK_MATERIAL.flatShading = false` and `ROCK_MATERIAL.userData.noBands = true`. For boulders and whalebacks (`recipe.size >= 9`), use `icosphere(2)` at LOD 0 and weld shared vertex normals by position so domes curve smoothly without low-poly triangular facets, while small stones (`size < 9`) retain flat non-indexed triangle normals. In `ROCK_MATERIAL.onBeforeCompile`, bump `normal` in `#include <normal_fragment_maps>` using `dFdx(rockH), dFdy(rockH)` (`perturbNormalArb` math).
   - **CDF-normalized `fbm` for moss/lichen patches:** `fbm()` in `src/proc/glsl.ts` has mean `0.484` and standard deviation `0.125` (it almost never exceeds `0.72`). Always normalize `fbm` with `smoothstep(0.32, 0.68, fbm(...))` before thresholding cap-moss (`vec3(0.055, 0.095, 0.025)`) and crustose lichen (`vec3(0.18, 0.20, 0.145)`) patches on `vRockN.y > 0.42`.
4. **Record matched in-game views & run the 4-part calibrated metric (`refs/rocks/shield-audit/capture.mjs`, `measure.mjs`):**
   - Serve the worktree on port `5250` and capture both the clay/till forest floor (`?nomenu&bench&hour=11&at=38.5,-1.5,0`) and the Canadian Shield bedrock ridge (`?nomenu&bench&hour=11&at=128.7,21.5,0`, `siteAt().rock === 0.85`).
   - Evaluate `shieldOutcropScore = 0.30 * coverSubscore + 0.25 * scaleSubscore + 0.20 * shapeAndTextureSubscore + 0.25 * colourSubscore`, where `colourSubscore` checks rock-pixel `R - B` warmth (`[+12, +38]`), saturation (`[0.12, 0.34]`), and mid-value luminance (`[110, 178]`), calibrated so a near-white cool slab frame (`upland-ridge-white-slab-mismatch.png`, `R-B = -9.3` on rock boxes) scores `0.853` (`< 0.95` fail) while the nature reference (`shield-ridge-ref.png`) scores `1.000` and the corrected pink-grey granite + moss/lichen frames score `0.989–0.994`.

## Mistakes to avoid
- **Using sRGB numbers (`0.45–0.60`) in `THREE.Color.setRGB()` or shader `diffuseColor.rgb`:** Both are linear reflectance in Three.js `r180`; values around `0.50` behave like snow/chalk and wash out to cool white under sky IBL and ACES tone mapping.
- **Thresholding raw `fbm()` above `0.74`:** Raw `fbm()` has mean `0.484` and SD `0.125`, so `smoothstep(0.74, 0.92, fbm)` evaluates to `0.0` almost everywhere. Always normalize via `smoothstep(0.32, 0.68, fbm)`.
- **Running only a subset of test files instead of full `npm test`:** Changes to `generateChunk` require re-pinning `tests/proc.test.ts`'s world-chunk baseline digest with an explanatory comment.
