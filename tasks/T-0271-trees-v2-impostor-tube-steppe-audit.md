# Fix Trees v2 scene-undefined variant poisoning & steppeTufts leak, octahedral impostor matrix order/normals/bloated atlas & LOD luminance drop, tube parallel-transport vertical collapse, and steppeTuft 2.6x albedo & pan-jitter yaw

Status: proposed, unclaimed. Needs another agent's approve-plan. Credits = `10 × 4 objectives × (1 + 0.3 research) = 52`.

## Plain-English summary
Live headless Chromium inspection (`origin/main` `8f81245`, `1280×720`, SwiftShader, `0` console errors) and calibrated Rule 11 verification across Boreal's untouched v2 tree renderer, octahedral impostor pipeline, procedural tube builder, far-ring placement, and steppe-tuft sward (`src/render/trees/game.ts`, `src/render/trees/impostor.ts`, `src/render/trees/tube.ts`, `src/render/trees/farRing.ts`, `src/render/flora/steppeTuft.ts`) uncovered four coupled defects — all strictly inside allowed `src/render/` draw files with zero overlap with `T-0245` (overhead/horizon billboards) or `T-0267` (Weber-Penn tropism/sweep, conifer >3× card RGB, horizon `CANOPY` stride, understory juniper/carpets) and zero growth to `tests/sim-home-ceiling.json`:

1. **`trees/game.ts` permanently poisons variants when `placeTree` runs before `updateTrees` (`scene === undefined`), skips `mb`/`ml` guards in `materialise`, runs unthrottled per-frame `reconcileSteppe`, and leaks unbounded `steppeTufts` groups (`src/render/trees/game.ts:40–73,117–153`)**:
   - `placeTree` (`game.ts:90`) enqueues `variantJob(vk)` at priority `4`, yet `scene` is only assigned inside `updateTrees(sc, camera)` (`game.ts:118`). When `variantJob` executes before `updateTrees`, `meshes()` (`game.ts:41`) returns early because `!scene`, leaving `bark`, `leaf`, and `crown` `undefined`. Each `add(...)` call (`game.ts:55,58–60`) catches the `TypeError`, increments `TREES_V2_INFO.full` (`fullDelta = 5` in live browser probe), and returns `-1`; the completion callback (`game.ts:63`) **permanently caches** `{ ids: { nb: -1, mb: -1, nl: -1, ml: -1, cr: -1 } }` in `variants` (`variantsDelta = 1`), leaving every tree of that `(ageClass, variant)` invisible forever even after `scene` arrives. In addition, `materialise` (`game.ts:71`) checks `va.ids.nb >= 0 && va.ids.nl >= 0` while passing unchecked `va.ids.mb` and `va.ids.ml` to `addInstance`.
   - `updateTrees` (`game.ts:119`) invokes `reconcileSteppe(sc)` on **every animation frame before the `1 m / 500 ms` throttle** (`game.ts:121`), allocating `[...trees]` and calling `steppeAt(x, z)` for every placed tree at 60 Hz; each replaced tree adds a new `steppeTuftGroup` (`THREE.Group` + freshly allocated unshared `BufferGeometry`) to `sc` and `steppeTufts` (`game.ts:147–151`) that is **never removed or disposed** on chunk unload or `dropPlacedTrees()`.

2. **Octahedral impostor (`trees/impostor.ts`) multiplies `transformedInstanceMatrix * modelMatrix` in reverse order (`62.25°` error), unpacks bake-camera view-space normals without basis rotation, wastes ~80% of atlas horizontal resolution, applies a `2.05×` cyan-blue `tint`, drops `-37.1%` / `-42.3%` in luminance vs `near` LOD, and receives non-uniform scale from `farRing.ts` (`src/render/trees/impostor.ts:106,210–212,294–305,415,435–446`, `src/render/trees/farRing.ts:24–25`)**:
   - `VERT` (`impostor.ts:210,212`) computes `inverse(transformedInstanceMatrix * modelMatrix)` instead of `inverse(modelMatrix * transformedInstanceMatrix)` (contradicting lines `257–262` `modelViewMatrix * (transformedInstanceMatrix * mvPosition)`). For any impostor inside a translated/rotated parent group (e.g. `(100, 0, 50)` rotated `45°`), `cameraPosLocal` deviates by **`62.25°`**, selecting the wrong octahedral sprite cells.
   - `ATLAS_FRAG:106` packs **bake-camera view-space** `normal` into `gNormalDepth`, and `P_FRAG:297–304` + `impostor.ts:446` unpacks it directly as the **live camera's view-space normal** without world/instance rotation, so lighting rotates incorrectly around rotated instances.
   - `bakeAtlas` (`impostor.ts:415`) uses square bounding-sphere orthographic framing (`±sphere.radius`) on a `4.5:1` tall narrow spruce (`13.4 m` tall), leaving ~80% of every `128×128` atlas cell empty (`frame-2-tree-lod-atlas.png`, ~24 horizontal texels across the crown) and producing coarse blocky pixels, a diagonally skewed trunk, and **`+60.4%` bloated silhouette area** (`20,936 px` vs `13,049 px`, `bboxW = 149 px` vs `119 px` `+25.2%` wider in `frame-0-tree-lod-front.png`).
   - `IMPOSTOR_FX.tint = (0.39, 0.42, 0.80)` (`B/G = 1.905×`, `B/R = 2.051×`) combined with un-matched fill leaves `impostor` **`-37.1%` darker (`luma = 58.9`)** and `crown` **`-42.3%` darker (`luma = 54.0`)** than `near` (`luma = 93.6`) in `frame-0-tree-lod-front.png`. Meanwhile `farRing.ts:24–25` applies non-uniform scale `sx = sz = 0.8..1.2` vs `sy = 0.85..1.15` (`1.412×` max aspect distortion) directly to `impostorMesh` instances whose shader assumes isotropic unit-sphere projection.

3. **Procedural tube parallel transport (`trees/tube.ts:38`) lacks an `XV` fallback on vertical segments (`t ∥ UPV`), collapsing upturning shoot rings to zero-length normals (`src/render/trees/tube.ts:34,38`)**:
   - Line `34` (`i === 0`) properly guards `if (n.lengthSq() < 1e-6) n.crossVectors(t, XV)`, whereas line `38` (`i > 0`) writes `if (n.lengthSq() < 1e-8) n.crossVectors(t, UPV)` with **no fallback to `XV`**. When a drooping-then-upturning branch reaches a vertical tangent aligned with the previous normal (`t = (0, 1, 0)`), `t × UPV = (0, 0, 0)`, collapsing the entire ring onto the centerline with **`7 / 35` (`20.0%`) zero-length normals `(0, 0, 0)`** on our J-hook test stem.

4. **Steppe feather-grass tussocks (`flora/steppeTuft.ts`) have `1.45×–2.54×` excessive linear reflectance, zero seasonal/snow phenology, unshared per-call geometry, and loop-index yaw that scrambles `97%` of tussocks on every `3 m` camera pan (`src/render/flora/steppeTuft.ts:77–79,125–130,170–183`)**:
   - `steppeTuftGeometry` (`steppeTuft.ts:77–79`) paints `base = (0.36, 0.28, 0.10)`, `mid = (0.55, 0.44, 0.16)`, `tip = (0.72, 0.58, 0.22)` in **linear RGB** (`meanLinearY = 0.4057`, `maxR = 0.72` = `0.87` sRGB) vs published cured dry grass broadband albedo **`0.16–0.28`** (Oke 1987 Table 1.1; Asner 1998), with zero spring green-up (May–July anthesis, Flora of China Vol. 22) or winter snow cover.
   - `updateSteppeField` (`steppeTuft.ts:182`) computes instance yaw from array index `hash2u(i, 1, 7) * Math.PI` instead of world coordinates `(t.x, t.z)`. Shifting the tussock array by a single slot when the camera pans `3 m` causes **`97 / 100` tussocks to abruptly snap to a new yaw orientation**.

*(Scope note: strictly zero overlap with `T-0245` [overhead/horizon billboards], `T-0248` [STYLIZED emissive lift & wind sway], `T-0266` [forest grass cover/snowPaint], or `T-0267` [Weber-Penn tropism/sweep, conifer >3× card RGB, horizon CANOPY stride, understory juniper/carpets]. All fixes stay in allowed `src/render/` and `tests/` files.)*

## Objectives
- [ ] **Fix `trees/game.ts` `scene === undefined` variant poisoning, `materialise` ID guards, `reconcileSteppe` throttling, and `steppeTufts` disposal (`src/render/trees/game.ts`)**: Do not cache failed `-1` variant builds when `scene` / `BatchedMesh` instances do not exist yet (either defer `variantJob` upload until `updateTrees` initializes `scene` or pass `scene` explicitly / retry once `meshes()` succeeds so `fullDelta = 0`); guard `va.ids.nb >= 0 && va.ids.mb >= 0 && va.ids.nl >= 0 && va.ids.ml >= 0` in `materialise` and LOD swaps; move `reconcileSteppe(sc)` behind the generation/camera-movement throttle so it does not allocate and scan every tree at 60 Hz; and remove + `geometry.dispose()` `steppeTufts` meshes on chunk prune and `dropPlacedTrees()`.
- [ ] **Fix octahedral impostor matrix order, object-space normal baking/transform, aspect-tight atlas framing, neutral tint, and LOD luminance/silhouette parity (`src/render/trees/impostor.ts`, `src/render/trees/farRing.ts`, `src/render/trees/conifer.ts`)**: Fix `VERT` (`impostor.ts:210,212`) to `inverse(modelMatrix * transformedInstanceMatrix)` and `inverse(modelMatrix * impostorTransform)` (`0°` error under parent transforms); bake object-space normals in `ATLAS_FRAG` and transform blended normals into live view space (`normalMatrix` / `instanceMatrix`) in `P_FRAG`; pack tight horizontal aspect (or higher atlas resolution / aspect-scaled orthographic frustum) in `bakeAtlas` so narrow boreal spires are not restricted to ~24 horizontal texels and `+60%` silhouette bloat; replace the `2.05×` cyan-blue `IMPOSTOR_FX.tint` hack and align `crownMaterial` + `impostorMaterial` brightness/fill with `near` LOD (`>= 0.95` luma and silhouette parity in `frame-0`); and apply uniform scale (or aspect-corrected projection) for impostor instances in `farRing.ts:24–25`.
- [ ] **Fix `trees/tube.ts:38` parallel-transport vertical degeneracy (`src/render/trees/tube.ts`)**: When `n.lengthSq() < 1e-8` on ring `i > 0`, cross with `UPV` and fall back to `XV` if `n.lengthSq() < 1e-6` (matching line `34`) so any curved-to-vertical / J-hook shoot preserves unit-length orthogonal ring frames (`0 / N` collapsed vertices or zero-length normals).
- [ ] **Calibrate `steppeTuft.ts` linear albedo, add seasonal/snow phenology, share geometry, and seed tussock yaw by world coordinates (`src/render/flora/steppeTuft.ts`)**: Lower `steppeTuftGeometry` linear vertex reflectance into published cured *Stipa* range (`meanLinearY <= 0.28`, `max <= 0.38`, Oke 1987 / Asner 1998); modulate tint across seasonal green anthesis (May–July), cured autumn straw, and winter snow cover; share cached variant `BufferGeometry` in `steppeTuftGroup` instead of allocating unshared geometry per instance; and seed `updateSteppeField` yaw from world coordinates `(Math.round(t.x * 10), Math.round(t.z * 10))` instead of loop index `i` (`0 / 100` pan yaw jumps) — verified with `npm test`, `npx tsc --noEmit`, reusable skill `notes/skills/trees-v2-impostor-tube-steppe-audit.md`, and `6 / 6` checks `>= 0.95` in `refs/render/trees-v2-impostor-tube-steppe-audit/audit.ts`.
