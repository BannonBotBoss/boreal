# Fix `Generate universe` Big Bang skip & `Forest only (legacy)…` seed override + `CosmosSphere` leak, `Play as` Snowshoe Hare/Deer running wolf predator autonomy & wolf UI/howl, Autonomous wolf `0.556 m` hillside deadlock (`+514.5°` spin, `+1/s` free energy, unwired scents/water), and `Data (U)` rebind hijack + `Pause -> Graphics` dual Quality / `probeCap` clobber & white-on-white `<select>` contrast

## Plain-English summary
- Clicking **`Generate universe`** a second time (after a previous Big Bang intro completed or was skipped) **never plays the new universe's Big Bang opening** (`cineShownOnSecondGenerate = false`; `frame-0` drops straight onto the forest floor with `?noprobe=1`), because `main.ts:243` calls `clearWorldSaves(true)`, preserving `introComplete: true` so `bootChoice('sphere', true, null)` skips `'sphere'`. Meanwhile, **`Universe options… -> Forest only (legacy)…`** writes `boreal.seed.v1 = "424242"` without clearing `boreal.universe.seed.v1` (`main.ts:252–254`), so `main.ts:279–280` silently overrides it on reload with `worldSeedFromUniverse(u) = 1587008242`; `opening.ts:262–270` (`stop()`) never calls `sphere?.dispose()` (leaking `CosmosSphere`'s WebGL2 context and `rAF` loop); and `menu.ts:73` displays broken grammar (`"Leave blank mint by pressing New seed."`).
- Switching species live via **`Pause -> More -> Player`** (`Play as`: `Wolf -> White-tailed deer -> Snowshoe hare`) leaks grey-wolf predator logic into herbivore playables: enabling **`Autonomous: On`** while embodied as a **Snowshoe hare** runs `autonomousWolfStep()` (`WOLF_AGENT`, `main.ts:675`), turning a herbivorous hare into a **predator stalking `hare:6`** (`"AUTONOMOUS · 12:07 · WALK ... · following hare hare:6"`, `frame-1`)! Meanwhile `main.ts:795` still displays wolf hunting/lock hints (`Q lock`), `main.ts:437` lets hares and deer press `H`/`G` to howl and growl like wolves, `main.ts:696–713` leaves `driveHold`/`driveCommitted` latched when switching off `wolf`, and `buildScene.ts:151` swaps rigs without dropping held prey or resetting `autonomous`.
- Enabling **`Autonomous: On`** as the grey wolf on gently sloping staged Kenora terrain (`frame-2`, `recording.webm = 116,365 B`) spins the wolf **`+514.5°` (`8.98 rad`) in `0.7 s`** and then **deadlocks permanently (`0.0000 m` displacement across `4 / 6` samples)** on a single ground stone (`stones:1:-1:35`) in a wide-open meadow, because `wolfGround(pose)` (`autonomy.ts:45–50`) tests `|heightAt(to) - heightAt(pose)| <= 0.45 m` at `plan.ts:157`'s detour endpoints (`wolfGroundHeight = 3.737 m`, `stoneGroundHeight = 4.293 m`, `Δh = 0.556 m > 0.45 m`) instead of checking local step slope! While frozen in `route.motion = 'wait'` (`brain.problem = 'recover'`), `main.ts:691` lets legacy `AnimalBrain.expend()` refill **`+3.43` free energy (`+1.0/s`, `74.91 -> 78.34 -> 80/100`) without eating** — violating energy conservation (`PROJECT-RULES`). In addition, `main.ts:675–678` never passes `scents` or `water`/`waterLevel` to `autonomousWolfStep()` (leaving `autonomy.ts:157,160` dead), while the thirsty bypass (`?needs=water:15`, `main.ts:660–663`) oscillates `yaw` (`1.40 -> 2.19 -> 5.33 -> 1.40 rad`) without obstacle routing.
- Pressing **`U`** while rebinding any action (e.g., `Howl`) inside **`Pause -> Controls`** (`.ctl-screen.capturing`) is **hijacked by `dataPanel.ts:89–97`** (`e.stopImmediatePropagation()` in capture phase), popping `#data-panel` open over Controls (`dataPanelHiddenAfterU = false`, `howlKeysText = "H"`, `capturingAfterU = true`), while `dataPanel.ts:232–241` runs an uncancellable infinite `requestAnimationFrame(pad)` loop from page load even while closed. Inside **`Pause -> Graphics`** (`frame-4`), two conflicting Quality controls fight each other: the top `<select aria-label="Quality">` (`menu.ts:96–102`) sets `GOVERNOR.auto = false; GOVERNOR.tier = 0 (Ultra)` **without updating `renderStore`** (`quality.auto` stays `true` in `boreal.render.v1`, reverting on reload), **permanently clobbers the measured hardware `GOVERNOR.probeCap`** (`if (i < GOVERNOR.probeCap) GOVERNOR.probeCap = i`), overlaps `"Boreal"` behind `"Graphics"`, and renders unreadable light-on-white `<select>` text (`< 1.3:1` contrast vs WCAG 2.1 AA `4.5:1`).
- What stays the same: all existing keyboard, mouse, and gamepad bindings, Rust simulation ownership (`AGENTS.md`), and prior audit tasks `T-0001..T-0298` (zero overlap with `T-0285`, `T-0290`, `T-0296`, `T-0297`, `T-0298`).
