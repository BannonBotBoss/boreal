This machine has no headset. The forest after the landing, on software graphics, was about 0.7 s a frame (median 700 ms, p95 1.4 s), 247 draw calls, 659k triangles. That is SwiftShader, not a Quest 3. 60 fps is the cap the headset session applies. It was not measured on a device.
