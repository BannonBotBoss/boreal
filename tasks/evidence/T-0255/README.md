# T-0255 frames

SwiftShader, Chrome, 1280×720. Before home is main `8051065f`. After home and after pole are this branch. Frame time about 0.8 s. No page error.

`before-pole.png` was shot on the cover-map branch, so its land is already tan and green. Use it for the width of the peach band. The land colour is T-0254. `after-pole.png` is this branch only: the band is a thin line and the land is still the vertex green.

`ref-apollo17.png` is Apollo 17 AS17-148-22727, NASA, 7 December 1972. https://images.nasa.gov/details/as17-148-22727

Peach pixels (r > 150 and r exceeds g and b by 18) on the home frame: 1372 before, 829 after. The pole frame is the one that shows the band as a line.
