## What Was Built
1. **Pure Encounter Threat (`src/audio/adaptiveStems.ts`)**:
   - Added `encounterThreat(input: EncounterInput): number` driven exclusively by real predator-prey encounter state (Rule 5 transactional rule; no timers or random pulses):
     - Returns `1` when the player wolf has an active hunt lock on prey (`huntLock.key !== undefined`), when the autonomous wolf is pursuing a hare (`wolfReadout(view.playerBrain)` with `targetKey?.startsWith('hare:') && action === 'pursue'`), or when the mother wolf is charging the fox (`view.playable.id === 'wolf' && driveHold`).
     - For any nearby hare (`view.hares.list()`, `h.state === 'flee'`) or deer (`view.audibleAnimals()`, `a.problem === 'flee' || a.problem === 'escape'`) actively fleeing within `HUNT.safeDistance` (`35 m`, `SYSTEM_PROPERTIES.hunt.safeDistance`), returns `clamp01(1 - d / safeDistance)` when walking/standing and `Math.max(THREAT_ON, clamp01(1 - d / safeDistance))` when running/sprinting/jumping (`modes.mode === 'run' || modes.mode === 'sprint' || view.playerBrain.motion === 'run' || view.playerBrain.motion === 'jump'`), so an active chase inside `safeDistance` immediately crosses `THREAT_ON` (`0.5`) and turns the tension stem on.
   - Added `capStemSum(w)` so smoothed stem transitions (`stepStems`) as well as steady-state targets (`stemWeights`) never exceed `STEM_SUM_CAP` (`1.0`).
   - Exposed `state: () => ({ cur: { ...cur }, threatState: { ...threatState }, threat: lastThreat })` on `startStems` (`src/audio/adaptiveStems.ts`) and `stemsState: () => stems?.state()` on `createMusic` (`src/audio/music.ts`).
