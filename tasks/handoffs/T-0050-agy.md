## What Was Built
1. **Bloom-Window Triangle Filtering in `stripFlora` (`src/render/geometry.ts`)**:
   - Before `stripFlora(g, day = WEATHER.day)` deletes `aFall`, `aOrgan`, and `aBloom`, it checks `aBloom` using the same window condition as the field shader (`src/render/flora/flora.ts:91`): `b.getY(i) > 0 && (day < b.getX(i) || day > b.getY(i))`.
   - When any vertex is outside its bloom window on `day`, `stripFlora` filters `g.index` triangles to drop every triangle touching an out-of-window vertex, compacts `position`, `normal`, and `color` attributes to the kept vertices, and updates `g.setIndex(tris)` and `g.computeBoundingSphere()`.
   - Leaves `['color', 'normal', 'position']` on `PROP_MATERIAL` with zero additional materials or shader programs.
2. **Day-Keyed `propCache` and `propBloomMask` (`src/render/geometry.ts`)**:
   - Updated `propFlora`'s cache key to `${kind}:${spec.id}:${v}:${detail}:${WEATHER.day}` so changing `WEATHER.day` never returns a stale cached geometry from another day.
   - Added `propBloomMask(day = WEATHER.day)` (5-bit mask over `[FORAGE_SPEC, ...HERB_SPECS]`) and `syncChunkProps(chunks, day = WEATHER.day)`.
3. **In-Place Chunk Prop Batch Rebuild (`src/render/batch.ts`, `src/render/buildScene.ts`)**:
   - Added `batch.replace(updates, mat = PROP_MATERIAL)` in `src/render/batch.ts` to replace the 3 LOD levels of updated items (`plant` and `forage`), dispose and remove the old `PROP_MATERIAL` `BatchedMesh` from `chunk.root`, build and attach the replacement `BatchedMesh`, and reset `level` on those instances so `batch.update` immediately selects their active LODs.
   - In `src/render/buildScene.ts`, each chunk records `bloomMask = propBloomMask()` when generating its entities, and both `sync` and `draw` call `if (syncChunkProps(chunks.values())) lastBatchLod = -1;` so chunks already in `chunks` rebuild their `plant` and `forage` props whenever `WEATHER.day` crosses a bloom window.
4. **Unit Test & Calibrated Measurement (`tests/flora.test.ts`, `refs/flora/t0050-prop-bloom/`)**:
   - Added test `'stripFlora and chunk props follow the flora bloom window (T-0050)'` in `tests/flora.test.ts`.
   - Added calibrated measurement script `refs/flora/t0050-prop-bloom/measure.mjs` (`refs/flora/t0050-prop-bloom/measure.json`) and headless Edge capture script `refs/flora/t0050-prop-bloom/capture.mjs` (`refs/flora/t0050-prop-bloom/capture.json`).
