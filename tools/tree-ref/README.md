# Black spruce reference (Picea mariana)

Photos from Wikimedia Commons, downscaled to 1280 px. SOURCES.json lists each file's page, author, licence (CC BY / CC BY-SA / PD) and location.
They are references for crown shape (narrow spire, drooping tiers, club top), bark and needle colour; measured medians are in src/core/flora/trees/forms.ts.
Attribution: see SOURCES.json. The CC BY-SA files keep their licence; they are not part of the game build.
